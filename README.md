# Página de Previsão do Tempo

## Sobre o projeto

Este projeto consiste em uma página web de previsão do tempo, desenvolvida como atividade acadêmica.

A aplicação permite visualizar a data e hora atual, consultar informações meteorológicas de uma cidade e visualizar uma sugestão de cidade para consulta. O projeto também possui um vídeo integrado do YouTube e uma seção informativa sobre alimentação saudável.

## Funcionalidades

- Exibição da data e hora atual;
- Consulta da previsão do tempo;
- Busca de previsão por cidade;
- Exibição da temperatura;
- Exibição da condição climática;
- Exibição da umidade;
- Exibição da velocidade do vento;
- Sugestão de cidades durante a pesquisa;
- Vídeo incorporado do YouTube;
- Botão para voltar ao topo da página.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API OpenWeatherMap
- YouTube

## Objetivo

O objetivo do projeto é desenvolver uma página web interativa utilizando HTML, CSS e JavaScript, aplicando conceitos de desenvolvimento web e integração com uma API externa.
